# NHIMC UI Core

For requests that create or change an NHIMC-branded web interface, start with `bootstrap.md`, then load and follow `skills/nhimc-worktool/SKILL.md`. Treat the registries it names as the source of truth. Generate the default deliverable as one self-contained, offline `index.html` by using the registered builder; do not hand-copy the protected application frame into business content or deliver CSS, JavaScript, font, image, or documentation sidecars. Do not claim a platform is ready until its adapter has been loaded and checked.
