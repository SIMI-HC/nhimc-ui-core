GETTING STARTED

설치 가이드

NhimcDesign(NHIMC Worktool)을 GitHub로 옮긴 프로젝트입니다. URL 하나로 6개 환경(ChatGPT Web · Claude Web · Gemini Web · Codex · Claude Code · Gemini CLI)을 준비하고, 이후에는 자연어로 화면을 요청합니다. ZIP 업로드는 필요 없습니다.

STEP BY STEP

설치하고 사용하기

  1. 1. 준비 — AI에게 저장소 주소와 아래 문장만 전달하고 결과 확인

    https://github.com/SIMI-HC/nhimc-ui-core.git
bootstrap.md만 읽고 NHIMC UI Core를 준비해줘.

    AI가 환경을 스스로 판별해 공식적으로 가능한 방식으로 준비합니다. 승인 창이 뜨면 승인하세요. 지원되지 않는 설치를 우회하거나 성공했다고 가정하지 않습니다. 기존 NhimcDesign 스킬(nhimc-worktool)이 있으면 같은 이름으로 업데이트됩니다.

    AI가 platform, projectVersion, defaultFrame, defaultTheme, installationMode와 상태를 보고하고 이 Design Guide를 열어 줍니다. 열 수 없는 환경이면 파일이 다운로드됩니다.

    • READY — 이 환경에서 빌더를 실제로 호출해 검증된 index.html을 전달할 수 있습니다.
    • WEB_BOOTSTRAP — 저장소와 Skill만 읽는 context-only 상태입니다. Web Runtime이 정본 Frame·폰트·아이콘을 씌우며 오프라인 검증 파일은 아닙니다.
    • UNSUPPORTED — 저장소 또는 Skill을 읽을 수 없습니다.

  2. 2. 화면 요청 — 자연어 또는 프롬프트 만들기

    병원 이송업무 관리 화면 만들어줘.

    Layout·Theme까지 직접 고르려면 프롬프트 만들기로 만든 프롬프트를 붙여 넣으세요. AI가 업무에 맞는 메뉴와 Page를 정하고, Page마다 등록 Component와 Layout Primitive로 화면을 채웁니다.

  3. 3. 결과 받기

    로컬 호스트(Claude Code · Codex · Gemini CLI)에서는 AI가 Content만 조합한 저작 원본을 만든 뒤 브라우저 검증과 다운로드 전달까지 수행합니다. 정상 결과는 정확히 하나의 index.html이며 더블클릭하면 열리고 인터넷, 서버, 저장소, app.js, CSS, 이미지, 폰트 폴더가 필요하지 않습니다.

    웹 AI(ChatGPT Web · Claude Web · Gemini Web)는 빌더를 실행할 수 없으므로 Content와 <script src> 한 줄로 프롬프트 안에서 끝냅니다. 인터넷과 외부 스크립트를 허용하는 곳에서 열어야 하며, 화면 오른쪽 아래 “오프라인 HTML 저장” 버튼을 누르면 CSS·스크립트·폰트가 모두 들어간 HTML 파일을 받을 수 있습니다(인터넷 없이 열림). 브라우저 검증까지 거친 파일은 Claude Code · Codex · Gemini CLI에서 요청하세요.

    메뉴에 '재고 현황'과 '발주 관리'를 추가하고, 각 Page는 검색조건과 표, 페이지네이션으로 구성해줘.

    위는 이어서 요청하는 예시입니다. 메뉴를 바꿔도 Frame 소스는 수정되지 않습니다.

AI가 정하는 것

  • 업무 요구에 맞는 메뉴와 Page 수
  • Page마다 검색조건 · 표 · 카드 · 폼 · 차트 구성
  • 등록 Component 재사용, Layout Primitive로 여백·격자 통일

고정되어 바뀌지 않는 것

  • Frame · Header · 왼쪽 메뉴 · 상태 표시줄 · PRESENTATION의 Header·Controller와 Content Safe Area(헤더·컨트롤러를 피하라고 따로 요청할 필요 없음)
  • 일산병원 로고 · 아이콘 · Noto Sans KR · Theme
  • Component 모양과 상태(hover · focus · disabled)
